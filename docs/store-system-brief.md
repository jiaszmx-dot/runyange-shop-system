# 门店经营系统项目底稿

## 1. 项目定位

- 目标不是做一个单店收银工具，而是做一套可从样本店跑通、未来可复制到直营连锁和加盟体系的门店经营系统。
- 第一阶段服务对象是小儿推拿艾灸馆，后续需要支持多门店、多角色、多业务类型。
- 业务价值包括：
  - 提升收银和日常运营效率
  - 沉淀会员数据和复购经营能力
  - 规范员工提成、项目管理、商品管理和门店报表
  - 为未来连锁复制提供标准化操作系统

## 2. 当前已确认信息

### 2.1 时间与资源

- 目标周期：90 天内完成首个可上线、可部署、可实际使用版本

### 2.4 会员体系

- 用户充值任意金额后成为会员
- 不同充值档位均可享受统一会员价
- 不同充值档位可赠送不同服务和次数
- 会员体系核心元素至少包含：
  - 储值余额
  - 会员价
  - 赠送项目
  - 赠送次数
  - 消费记录
  - 回访记录

### 2.5 员工提成体系

- 服务提成：按项目固定提成
- 充值提成：按会员充值档位阶梯提成
  - 688 -> 5%
  - 1288 -> 8%
  - 2988 -> 10%

### 2.6 多店模式

- 直营店：总部拥有完整编辑权限
- 加盟店：总部可查看经营情况，但不能直接编辑加盟店收银或充值
- 该需求本质上是“多组织 + 多门店 + 差异化权限模型”

### 2.7 移动端诉求

- 管理员：希望拥有接近 PC 端的全部操作能力
- 收银员：希望可通过手机或平板开单、充值
- 员工：希望查看个人业绩和会员跟进
- 倾向形式：微信小程序

### 2.8 硬件与支付诉求

- 支持扫码枪
- 支持热敏小票打印
- 支持活动二维码核销
- 希望打通真实支付通道，避免款项进入个人账户
- 若真实支付接入难度过高，可先支持线下记账型支付方式：
  - 微信
  - 支付宝
  - 现金
  - 银行卡

## 4. 当前战略判断

### 4.1 这是一个“门店经营系统”，不是单点工具

- 系统设计必须从第一天就考虑：
  - 多门店隔离
  - 多角色权限
  - 订单、会员、储值、卡项、库存、提成之间的数据一致性

### 4.2 90 天目标具备可行性，但前提是范围切分得非常严格

- 在现有人力和时间下，不适合把所有细节一次性做到最深
- 更可行的做法是：
  - 核心业务闭环必须全有
  - 但每个模块的第一版深度要控制
- 例如可以区分：
  - 第一版必须有：收银、会员、订单、提成、项目商品、基础报表、多店权限
  - 第一版可简化：复杂营销自动化、复杂审批流、深度 BI、自定义打印模板设计器、复杂加盟结算

### 4.3 真实支付接入是高风险点

- 真实支付可行，但受制于商户主体、商户平台配置、接口审核、证书和回调配置等外部条件
- 若外部资质或联调时间拖慢，应准备“先上线记账型收款，再升级真实支付”的备选路线

### 4.4 小程序是移动端的强候选，但不是唯一入口

- 对管理员来说，“小程序 + PC 后台”是较自然的组合
- 对收银员和员工来说，小程序适合高频轻操作
- 但打印机、扫码枪等硬件兼容性需要按具体机型验证

## 5. 当前最关键的待确认问题

1. 会员充值档位是否固定为少数几档，还是门店可自定义新增和修改？
2. 赠送内容是否只包含服务次数，还是也可能包含商品、代金券、优惠券？
3. 会员扣费是只扣储值余额，还是还要支持扣次卡、扣疗程包、扣赠送次数？
4. 是否需要一个会员对应多个孩子/家庭成员档案？
5. 是否需要预约排班能力？
6. 是否需要服务前后照片、健康记录、禁忌记录、调理建议等护理档案？
7. 商品库存是否按门店独立核算？
8. 调拨是否需要支持门店间调拨？
9. 收银订单是否允许一单多项目、多员工分摊提成？
10. 充值提成是否只奖励首充，还是续充也奖励？
11. 退款、撤单、反结算、错单修正流程如何定义？
12. 加盟店是否需要独立员工账号体系和独立经营报表？
13. 总部是否要向加盟店下发统一项目、价格和活动，还是加盟店可自行维护一部分？
14. 管理员是否需要通过微信给会员发送提醒或回访消息？
15. 小程序是否准备使用企业主体注册并完成认证？
